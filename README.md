Pasar Pagi — Cari Bedanya: a bright morning spot-the-difference game. Three original Indonesian morning scenes — a morning market, a morning coffee stall, and a morning train station — each with two near-identical pictures side by side and 7 hidden differences. Click a difference (or play with the keyboard: arrows + Enter), get a hint (H), zoom with the magnifier (M), and score in Rupiah: +Rp5.000 per find, a time bonus per scene, and a wrong click costs Rp1.000. All art is drawn in code with canvas primitives, all sounds are made with the Web Audio API — no borrowed assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and play. No build step, no network request: `game/` is plain static files.
